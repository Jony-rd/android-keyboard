Typing engine (engine/src/main/kotlin/dev/pboard/engine/decode, .../swipe)
- Original implementation. The relative magnitudes of the tap edit costs (omission, same-letter omission,
  insertion, same-letter insertion, transposition) and the idea of corner handling in gestures were informed by
  reading AOSP LatinIME (Apache-2.0, https://android.googlesource.com/platform/packages/inputmethods/LatinIME,
  native/jni/src/suggest/policyimpl/typing/scoring_params.cpp and core/layout/proximity_info_params.cpp).
  No LatinIME code was copied.
- Gesture decoding follows the published SHARK² method: P.-O. Kristensson and S. Zhai, "SHARK²: A Large
  Vocabulary Shorthand Writing System for Pen-based Computers", UIST 2004.
- The neural gesture decoder (swipe/NeuralSwipeDecoder.kt, SwipeModel.kt) is an original implementation of the
  published LSTM + CTC approach: O. Alsharif, T. Ouyang, F. Beaufays, S. Zhai, T. Breuel, J. Schalkwyk, "Long
  Short Term Memory Neural Network for Keyboard Gesture Decoding", ICASSP 2015, and T. Ouyang et al., "Mobile
  Keyboard Input Decoding with Finite-State Transducers", arXiv:1704.03987, 2017.

Parameter tuning
- A handful of decoder constants (spatial sigma, out-of-vocabulary prior; engine/src/main/.../decode) were
  selected on the TUNE splits of the human evaluation data in tools/data/human (Google TSI tap data,
  CC BY 4.0, Lertvittayakumjorn et al. UIST 2024; Wikipedia "Lists of common misspellings", CC BY-SA 4.0;
  see tools/data/human/splits/v1/ATTRIBUTION.txt). No data from those sets is included in the engine.

On-device translation (translate/, app/src/main/java/dev/pboard/ime/translate, docs/translate.md)
- Marian NMT (MIT License, Copyright (c) 2016 Marcin Junczys-Dowmunt, the University of Edinburgh, Adam Mickiewicz
  University; browsermt/marian-dev fork). translate/.../marian/MarianBinary.kt and Shortlist.kt read Marian's binary

  src/data/shortlist.{h,cpp}; translate/.../nn/SsruTransformer.kt re-implements the inference of Marian's transformer
  with SSRU decoder (src/models/transformer.h, src/rnn/cells.h, src/graph/node_initializers.cpp). No Marian code was

- SentencePiece (Apache License 2.0, Copyright 2016 Google Inc.), https://github.com/google/sentencepiece.
  Licence text: third_party/sentencepiece/LICENSE. translate/.../spm/SentencePiece.kt ports the normaliser
  (precompiled charsmap lookup, whitespace rules; normalizer.cc), the optimised unigram Viterbi (unigram_model.cc)
  and byte fallback / decoding (sentencepiece_processor.cc).
- Darts-clone (BSD 3-Clause, Copyright (c) 2008-2011, Susumu Yata), bundled in SentencePiece: the double-array unit
  layout and common-prefix search used by the charsmap lookup in SentencePiece.kt. Licence text:

- Firefox Translations models (Mozilla Public License 2.0, https://github.com/mozilla/translations): NOT included in
